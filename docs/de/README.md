# 🍄 Spores & Shadows — Deutsche Dokumentation

**Spores & Shadows** ist eine Minecraft-Mod (**Fabric 1.21.1**), die ein dynamisches und unbarmherziges Ökosystem für den Holzzerfall einführt. Keine Holzstruktur ist vor dem Zahn der Zeit und der Härte der Elemente sicher.

Die Mod ersetzt nahtlos jeden Holzblock in der Welt — egal ob vom Spieler platziert oder natürlich in Strukturen generiert — durch dynamische Varianten, die anfällig für Pilzbefall sind.
