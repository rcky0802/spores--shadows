# 🍄 Spores & Shadows — Documentation Française

**Spores & Shadows** est un mod pour Minecraft (**Fabric 1.21.1**) qui introduit un écosystème dynamique et impitoyable de décomposition du bois. Aucune structure en bois n'est à l'abri du passage du temps et de la rigueur des éléments.

Le mod remplace de manière transparente chaque bloc de bois présent dans le monde — posé par le joueur ou généré naturellement dans les structures — par des variantes dynamiques sujettes à l'infection fongique.
