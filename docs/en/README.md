# 🍄 Spores & Shadows — English Documentation

**Spores & Shadows** is a Minecraft mod (**Fabric 1.21.1**) that introduces a dynamic and unforgiving wood decay ecosystem. No wooden structure is safe from the passage of time and the severity of the elements.

The mod seamlessly replaces every wooden block in the world — placed by the player or generated naturally in structures — with dynamic variants subject to fungal infection.
